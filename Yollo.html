SLIDE 01 // INFERENCE

Find the person and joints.

YOLO pose inference returns a person box, seventeen body keypoints, and confidence values. Low-confidence joints can be ignored before the motion logic begins.

  • Normalize keypoints to the subject box
  • Reject unstable or incomplete detections
  • Retain a short history instead of judging one frame
SLIDE 02 // PRIVACY

Render geometry, not identity.

The presentation layer can replace the camera image with a skeleton-only canvas. Operators still see posture and system state while faces and environmental details remain hidden.

  • Optional raw-video suppression
  • Status and confidence remain visible
  • Local processing keeps footage off a cloud service

SLIDE 03 // TEMPORAL SCORE

Combine evidence over time.

A useful fall detector cannot rely on a horizontal body in a single image. It combines sudden vertical change, body angle, keypoint quality, and continued time near the floor.

  • Short history reduces one-frame false alarms
  • Thresholds live in settings instead of model code
  • Cooldown prevents repeated alerts for one incident

SLIDE 04 // RESPONSE

Record first. Notify safely.

Confirmed events create a local incident record. An optional adapter can forward a notification, but credentials belong in environment variables and never in a public source archive.

  • Timestamped local event log
  • Pluggable alert destination
  • Public release requires credential sanitization

ARCH_01 // MODULAR DESKTOP PIPELINE

Designed as separable systems.

The split makes camera handling, inference, fall logic, rendering, logging, and notifications easier to test and replace.

01 // INPUT

Camera lifecycle

Opens the source, validates frames, controls resolution, and releases hardware cleanly.

02 // VISION

Pose inference

Runs the compact pose model and converts detections into stable, normalized keypoints.

03 // LOGIC

Fall state

Evaluates posture and motion across a short time window with cooldown and recovery states.

04 // DISPLAY

Privacy renderer

Draws skeletons, state, confidence, and diagnostic data with optional source-video hiding.

05 // RECORD

Incident logger

Writes a timestamped local record so alerts can be audited and detector behavior reviewed.

06 // OUTPUT

Alert adapter

Sends an optional notification while keeping endpoints and secrets outside public code.
