ARCH_02 // MODULAR FIELD STACK

Separate the aircraft from the experiment.

The payload should collect repeatable data without turning experimental code into a flight-critical dependency.

01 // CAPTURE

RF sensor head

Directional antenna and embedded capture module produce timestamped signal observations.

02 // POSITION

Flight telemetry

Position, heading, altitude, and sweep state make each observation spatially meaningful.

03 // TRANSPORT

Modular link

A contained payload link prevents a sensor failure from interfering with the aircraft control system.

04 // VISUALIZE

Radar playback

Recorded observations become a browser radar, heatmap, timeline, and confidence trail.

05 // TEST

Known targets

Bench and field trials use controlled distances, orientations, and signal sources before operational claims.

06 // ETHICS

Privacy boundary

Research should minimize retained identifiers, document consent, and follow applicable radio and privacy rules.
